# 09. 탐지기의 두 자리를 공개 벤치마크에서: 상용 LLM이 쓰거나 다듬은 글

- 브랜치: `exp/09-slots-benchmarks`
- 마감: 12/11
- 장비: 로컬 GTX 1060 6GB. API 없음.
- 선행: 04(공개 벤치마크, 기존 탐지기), 08(탐지기의 두 자리)

## 질문

08은 Fast-DetectGPT와 Binoculars 안의 두 자리를 나눠 봤습니다.
- **채점 모델**은 글을 채점합니다.
- **기준 모델**은 "보통이라면 이렇게 쓴다"는 다음 토큰 분포를 줍니다.

08에서는 ChatGPT 이후 모델이 채점 자리에서는 돕고, 기준 자리에서는 해쳤습니다. 기준 2022 + 채점 2024는 AUROC 0.9998이었습니다. 반면 최신 단일 모델(2024)은 2022 단일 모델보다 나빴습니다(F 0.921 vs 0.968).

08의 한계는 데이터에 있습니다.
- 우리가 만든 초록 데이터입니다.
- 생성기가 작은 채팅 모델 2종(Llama-3.2-1B, Qwen2.5-1.5B)뿐이고, Llama 글은 어느 칸에서나 천장입니다.

09는 같은 설정을 04의 공개 벤치마크에 그대로 넣습니다.

- **Q1.** 상용·대형 LLM이 처음부터 쓴 글(RAID)과, 사람이 쓰고 LLM이 다듬은 글(APT-Eval)에서도 두 자리가 반대로 작용하나?
- **Q2.** 그 이득은 ChatGPT 경계 때문인가? ChatGPT 이전 쌍(2018, 2021)에서는 기준을 옛 모델로 바꿔도 이득이 없어야 합니다.
- **Q3.** "최신 단일 모델이 더 나쁘다"는 08의 사후 관찰이 미리 세운 가설로 재현되나?
- **Q4 (실용).** 시간을 나눈 설정이 04의 기존 탐지기(Binoculars-1B)와 s_0.9를 이기나? 주 시나리오는 AI가 다듬은 글(APT 강)입니다.

## 탐지기

**시간을 나눈 탐지기 (08과 같은 코드, `scripts/score_slots.py`)**
- 칸 r_s는 기준 vintage r, 채점 vintage s입니다. 대각선(r = s)이 보통의 단일 모델 설정입니다.
- 식은 04의 `scripts/baseline_scores.py`와 같습니다.
  - F (Fast-DetectGPT): 해석적 샘플링 불일치. 높을수록 AI.
  - Bi (Binoculars): log-PPL / X-PPL. 부호를 뒤집어 높을수록 AI.
- 글마다 자기 길이로 최대 200토큰을 씁니다(04, 07, 08과 같음).
- **주 칸은 2022_2024입니다.** 08에서 정한 "기준은 ChatGPT 직전, 채점은 최신" 조합입니다. 16칸 중에서 시험 데이터를 보고 고르지 않습니다.

**04에서 그대로 가져온 비교 대상 (다시 채점하지 않음)**

| 이름 | 모델 | 04 결과: RAID 채팅 sampling / APT 강 |
| --- | --- | --- |
| likelihood (ll24) | DatedGPT-2024 | 0.950 / 0.815 |
| s_0.9 | DatedGPT-2024, 2022 | 0.959 / 0.847 |
| s_0.75 | 같음 | 0.965 / 0.854 |
| Binoculars-1B (bino1b) | Llama-3.2-1B / -Instruct | 0.993 / 0.790 |
| Fast-DetectGPT (fdneo) | GPT-Neo-2.7B | 0.943 / 0.626 |

모델 예산은 비슷합니다. 시간을 나눈 탐지기는 1.35B 두 개, Binoculars-1B는 1.2B 두 개, s_λ는 1.35B 두 개를 씁니다.

## 측정 (`scripts/det09.py`)

- **비교와 묶음**은 det04와 같습니다. AI 그룹은 사람 그룹과 비교하고, 공격 그룹은 같은 공격을 받은 사람 그룹과 비교합니다.
- **주 묶음**: P1 = RAID 채팅 sampling(6개 생성기), P2 = APT 강.
- **지표**: AUROC, TPR@5%FPR(문턱은 그 비교의 사람 글에서 정함).
- **CI**: 출처 단위(RAID 사람 초록, APT 원문)로 2,000회 bootstrap합니다(seed 0). 모든 탐지기와 칸에 같은 표본을 쓰므로 차이는 짝지어 계산됩니다.
- **탐색**: 생성기별, 다듬은 LLM별, APT 도메인별 결과와 나머지 묶음(greedy, 채팅 이전, 공격, APT 약)입니다.

**채점 전 점검 (11/16, AUROC는 계산하지 않음)**
- **파이프라인**: 시험 글 12편(RAID 6, APT 6)을 네 vintage로 채점했습니다(`scripts/slots_check.py --yc-prefix yc04_`).
  - 대각 칸의 likelihood는 04 점수 파일(`yc04_<v>`)과 최대 차이 0.00000으로 같았습니다.
  - 교차 칸(2022_2024, 2024_2022, 2018_2021)은 두 모델을 직접 함께 올려 계산한 값과 F 0.004, Bi 0.0003 안에서 같았습니다.
  - 판정: PASS.
- **분석 코드**는 합성 점수로 확인했습니다(`tests/test_det09.py`, 그리고 실제 04 id·그룹·출처에 합성 칸 점수를 붙인 전체 실행).
  - 2022_2024 칸에만 효과를 심으면 H1~H3이 성립합니다. 심지 않은 H4와 H5는 불성립이고, 일반화 판정은 True입니다.
  - 효과가 없으면 모든 가설이 불성립입니다.
  - 기준이 다르면 어느 쌍이든 똑같이 이득을 보게 심으면 H2는 성립하고 H3은 불성립입니다.

## 가설

F와 Bi 각각, P1과 P2 각각에서 판정합니다. A(r_s)는 칸 r_s의 AUROC입니다.

| 가설 | 대비 | 성립 조건 |
| --- | --- | --- |
| **H1 (채점 자리)** | A(2022_2024) − A(2022_2022) | CI 하한 > 0 |
| **H2 (기준 자리)** | A(2022_2024) − A(2024_2024) | CI 하한 > 0 |
| **H3 (경계)** | [A(2022_2024) − A(2024_2024)] − [A(2018_2021) − A(2021_2021)] | CI 하한 > 0 |
| **H4 (최신 단일 모델)** | A(2024_2024) − A(2022_2022) | CI 상한 < 0 |
| **H5 (기존 탐지기와 비교, P2만)** | (a) A(2022_2024) − A(Binoculars-1B), (b) A(2022_2024) − A(s_0.9) | 각각 CI 하한 > 0 |

- **일반화**: H1과 H2가 두 탐지기, 두 주 묶음에서 모두 성립하는 경우입니다.
- H3의 대조는 04의 H5(시간 경계)와 같은 생각입니다. 기준을 옛 모델로 바꾸는 일을 ChatGPT를 사이에 둔 쌍과 ChatGPT 이전 쌍에서 각각 하고, 둘의 이득을 뺍니다.

## 판단 기준

| 결과 | 해석과 다음 단계 |
| --- | --- |
| 일반화 성립 | 08의 결과가 상용 LLM 글과 다듬은 글로 넓어집니다. 논문의 탐지 주장은 "기준 자리에는 ChatGPT 이전, 채점 자리에는 이후 데이터로 배운 모델"입니다 |
| H2가 P1에서만 성립 | 기준 자리의 손해는 처음부터 쓴 글에서만 보입니다. 주장을 그 범위로 줄이고, 다듬은 글에서는 채점 자리(H1)만 말합니다 |
| H2가 P2에서만 성립 | 반대로, 다듬은 글에서만 주장합니다 |
| H3 불성립 | 기준 자리의 이득이 ChatGPT 경계가 아니라 "다른 모델을 기준으로 쓰는 것" 자체에서 옵니다. 시간 해석을 약하게 씁니다 |
| H4 성립(두 주 묶음) | "최신 모델로 바꾸면 오히려 나빠진다"를 미리 세운 가설로 확인합니다. 논문에서 주장합니다 |
| H4 불성립 | 08의 사후 관찰은 작은 생성기의 글에 한정됩니다. 논문에서는 조건을 붙여서만 씁니다 |
| H5 (a)·(b) 성립(탐지기 하나 이상) | 시간을 나눈 탐지기를 논문 탐지 방법의 중심에 둡니다. s_λ는 더 단순한 변형으로 씁니다 |
| H5 (a)만 성립 | 기존 작은 탐지기보다는 낫지만 s_λ보다 낫지는 않습니다. 방법은 s_λ로 두고, 두 자리 결과는 "숨은 변수" 분석으로 씁니다 |
| H5 모두 불성립 | 탐지 방법은 s_λ입니다. 두 자리 결과는 분석으로만 씁니다 |
| **Runpod** | H5 (a)가 성립하면 Falcon-7B 비교의 상대가 s_λ에서 시간을 나눈 탐지기로 바뀝니다. 04의 규칙과 함께 사용자가 정합니다 |

## 미리 적어둔 예측 (2026-11-16, 시험 데이터 채점 전)

이 시점에 아는 것:
- 04의 결과(위 표, 이 글들에 대한 likelihood·s_λ·기존 탐지기 점수)와 08의 결과.
- 위 12편 점검(글마다 값이 같은지만 봄)과 합성 점수 점검.
- 시간을 나눈 탐지기의 AUROC는 이 데이터에서 하나도 계산하지 않았습니다.

예측 (AUROC):

| 칸 | P1 RAID 채팅 sampling | P2 APT 강 |
| --- | --- | --- |
| F 2022_2022 | 0.92~0.96 | 0.60~0.72 |
| F 2024_2024 | 0.89~0.95 | 0.58~0.72 |
| **F 2022_2024** | **0.97~0.995** | **0.80~0.90** |
| Bi 2022_2022 | 0.93~0.97 | 0.62~0.75 |
| Bi 2024_2024 | 0.90~0.96 | 0.60~0.74 |
| **Bi 2022_2024** | **0.975~0.995** | **0.80~0.90** |
| F, Bi 2018_2021 − 2021_2021 | −0.05~0.00 | −0.05~+0.01 |

- **H1 성립** (P1·P2, 두 탐지기). 이득은 P1에서 +0.02~+0.06, P2에서 +0.10~+0.25입니다. P2는 단일 모델 설정이 약해서(04의 Fast-DetectGPT 0.626) 오를 자리가 큽니다. 확신 높음(85%).
- **H2 성립.** P1에서 +0.03~+0.08, P2에서 +0.10~+0.25입니다. 확신 중간(70%). 상용 LLM 글은 DatedGPT-2024가 학습한 웹 글과 덜 닮아서, 08보다 기준 자리의 손해가 작을 수 있습니다.
- **일반화 성립.** 확신 중간(55%).
- **H3 성립.** 08에서 ChatGPT 이전 모델끼리는 대각선이 가장 좋았습니다. 그래서 대조 쌍의 이득은 0 아래, 경계 쌍의 이득은 0 위로 봅니다. 확신 높음(80%).
- **H4**: P1에서 성립(65%), P2에서는 불확실합니다(45%). 다듬은 글은 내용이 사람 것이라, 2024 모델이 "예상하는" 정도가 처음부터 쓴 글보다 작다고 봅니다.
- **H5 (a) 성립(65%), (b)는 불확실(40%).** Binoculars-1B는 DeepSeek·GPT-4o가 다듬은 글에서 약했습니다(0.648, 0.740). s_0.9(0.847)는 같은 두 모델로 이미 높습니다.
- **P1에서 Binoculars-1B(0.993)와 비교**(판정 없음, 설명용): 2022_2024 칸은 −0.02~+0.005로, 비슷하거나 조금 낮다고 봅니다.
- **탐색**
  - 채팅 이전 생성기(RAID): 2022_2024의 이득(H1, H2 대비)이 채팅 생성기보다 작습니다. 이득이 채팅 문체에서 오기 때문입니다.
  - paraphrase 공격: 2022_2024 칸이 Binoculars-1B보다 크게 떨어집니다(04에서 Δ가 가장 약했음). 0.80~0.90입니다.
  - APT 약: 2022_2024 칸이 0.68~0.78로 s_0.75(0.724) 근처입니다.
  - 다듬은 LLM별: Binoculars-1B 대비 이득은 DeepSeek·GPT-4o에서 가장 크고, Llama 계열에서 가장 작습니다.
