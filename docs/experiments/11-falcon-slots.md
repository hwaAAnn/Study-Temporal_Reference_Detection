# 11. 원 논문 설정의 두 자리: Falcon-7B와 Falcon-7B-instruct

- 브랜치: `exp/11-falcon-slots`
- 마감: 11/22
- 장비: Runpod GPU pod 1대(RTX 4090 24GB, bf16). 사용자가 충전한 뒤에만 띄웁니다. 로컬 6GB에는 7B 모델이 들어가지 않습니다.
- 선행: 04(공개 벤치마크, Runpod 규칙), 08·09(두 자리), 10(TiC에서의 재현, 로컬)

## 왜 하나

### 표준 설정이 이미 "두 자리" 모양입니다

08·09에서는 두 자리의 배치가 성능을 크게 바꿨습니다.
- 가장 좋은 배치: 기준 자리에 ChatGPT 이전 모델, 채점 자리에 ChatGPT 이후 모델
- 가장 나쁜 배치: 그 반대
- 최신 모델 하나를 두 자리에 다 쓰면 이전 모델 하나보다 나빴습니다.

두 탐지기의 원래 코드는 같은 두 모델을 같은 배치로 씁니다(2026-11-16 확인).
- **Binoculars** (`binoculars/detector.py`): observer = `tiiuae/falcon-7b`, performer = `tiiuae/falcon-7b-instruct`, bfloat16.
  - perplexity는 performer의 logit으로 구합니다.
  - cross-perplexity는 observer의 분포(softmax)를 performer의 logit으로 잽니다.
  - 그래서 우리 표기로 기준 r = Falcon-7B, 채점 s = Falcon-7B-instruct입니다.
- **Fast-DetectGPT** (`scripts/local_infer.py` 기본값): sampling = `falcon-7b`, scoring = `falcon-7b-instruct`. 마찬가지로 r = Falcon-7B, s = Falcon-7B-instruct입니다.
  - README는 2026-01-31부터 Llama3-8B/-Instruct 쌍이 더 낫다고 적고 있습니다(아래 한계).

두 모델이 본 글은 다음과 같습니다.
- **Falcon-7B**는 2023년 3월 초에 학습했습니다(모델 카드). 주 데이터는 RefinedWeb(웹 크롤, 79%)이고, 크롤 시점 범위는 공개되지 않았습니다. 학습 시점으로 보아 ChatGPT 이후 글은 거의 없습니다.
- **Falcon-7B-instruct**는 Falcon-7B를 2.5억 토큰으로 미세조정한 모델입니다(모델 카드).
  - 구성: Baize 65%, GPT4All 25%, GPTeacher 5%, RefinedWeb-English 5%.
  - 앞의 세 데이터는 각 출처에 따르면 ChatGPT, GPT-3.5-turbo, GPT-4가 만든 대화와 답변입니다. 모델 카드에는 적혀 있지 않으므로, 논문에 쓰기 전에 원 출처로 다시 확인합니다.

그러니 표준 설정은 "기준은 ChatGPT 글을 거의 안 본 모델, 채점은 ChatGPT 글로 미세조정한 모델"입니다. 08·09에서 가장 좋았던 배치와 같은 모양입니다.

### 질문

- Q1. **채점 자리**: instruct 모델을 채점 자리에 넣으면 좋아지나?
- Q2. **기준 자리 (판정 핵심)**: instruct 모델을 기준 자리에 넣으면 나빠지나? 즉 원래 설정이 "instruct 모델 하나로 두 자리"보다 나은가?
- Q3. **단일 모델**: instruct 모델 하나를 두 자리에 다 쓰면 base 모델 하나보다 나쁜가? 09의 "최신 단일 모델이 더 나쁘다"와 같은 모양입니다.
- Q4. **뒤집기**: 두 자리를 뒤집으면(기준 instruct, 채점 base) 네 칸 중 가장 나쁜가?
- Q5. **실용 (04의 Runpod 규칙)**: 원 논문 크기의 Binoculars와 Fast-DetectGPT가 우리 s_λ보다 나은가? 다듬은 글(APT 강)과 처음부터 쓴 글(RAID 채팅 sampling)에서 봅니다.

## 채점

- `scripts/score_slots_family.py --family hf`를 씁니다(10과 같은 스크립트). 08의 묶음 방식과 같습니다.
  - 모델 하나씩 GPU에 올려 글 묶음을 채점하고, logit을 fp16으로 RAM에 둡니다.
  - 그다음 네 칸을 GPU에서 계산합니다.
  - bf16 logit은 fp16 범위 안에서 정밀도 손실 없이 fp16으로 옮겨집니다.
- 모델 dtype은 bfloat16입니다(원래 Binoculars 코드와 같음).
- 앞 200토큰을 씁니다(08·09·10과 같음). 원래 Binoculars는 512토큰까지 씁니다.
- 토큰화는 토크나이저 기본값(`add_special_tokens=True`)입니다. Falcon 토크나이저는 BOS를 붙이지 않으며, 원래 Binoculars 코드도 같습니다.
- 4090(24GB)에는 7B 모델 하나만 올립니다. 묶음마다 모델 순서를 뒤집어 한 번만 바꿔 올립니다.
- 예상 시간은 설치·받기 약 15분, 채점 약 30분입니다. RTX 4090 Secure $0.89/h 기준으로 약 $1입니다(11/16 조회). 시간 제한 장치는 3시간으로 두어, 최악의 경우 약 $2.7입니다.
- 결과를 받으면 pod를 바로 terminate합니다. 실제 GPU, 시간, 비용은 결과에 적습니다.

## 파이프라인 확인 (pod에서, 본 채점 전에)

- **묶음 계산과 직접 계산:** 글 12편에서 모델 하나씩 logit을 fp32로 직접 계산해 네 칸을 구하고, 묶음 계산과 비교합니다.
  - 허용치는 F 0.05, Bi 0.01입니다. bf16은 배치 구성에 따른 흔들림이 fp16보다 커서 08보다 넓게 잡았습니다.
  - 계산 순서가 틀리면 차이가 이보다 훨씬 큽니다.
  - 넘으면 본 채점을 하지 않고 멈춥니다.
- **정상 범위:** base 모델의 토큰당 손실이 사람 초록(H19)에서 2~4 nats 안이어야 합니다. 벗어나면 불러오기나 토큰화가 틀린 것으로 봅니다.
- 이 확인에서는 AUROC를 계산하지 않습니다.

## 가설 (Falcon 점수 계산 전, 2026-11-16)

F와 Bi 각각, 묶음 각각(H19/C19, B/C, P1, P2)에서 판정합니다. O = base_inst(원래 설정)입니다.

| 가설 | 대비 | 성립 조건 |
| --- | --- | --- |
| **H1 (채점 자리)** | A(O) − A(base_base) | CI 하한 > 0 |
| **H2 (기준 자리, 핵심)** | A(O) − A(inst_inst) | CI 하한 > 0 |
| **H3 (단일 모델)** | A(inst_inst) − A(base_base) | CI 상한 < 0 |
| **H4 (뒤집기)** | A(inst_base) − A(base_base), A(inst_base) − A(inst_inst) | 둘 다 CI 상한 < 0 |
| **H5 (실용, P1·P2)** | A(s_0.9) − A(O) | P2에서 CI 하한 > 0이면 "다듬은 글에서 s_λ가 원 논문 설정보다 낫다". P1은 설명용(판정 없음) |

- **천장 규칙(08과 같음):** 비교하는 두 칸이 모두 AUROC ≥ 0.998이면 그 묶음은 그 가설의 판정에서 뺍니다.

## 한계 (미리)

- **base와 instruct의 차이는 학습 데이터의 연도만이 아닙니다.** instruct 조정은 말투와 형식을 바꾸고, 분포도 뾰족하게 만듭니다. 그래서 이 실험은 깨끗한 연도 대비가 아니라, "표준 설정이 우리 결과와 맞는 모양인가"를 보는 보조 근거입니다. 인과 근거는 연도만 다른 08~10입니다.
- **Falcon-7B의 크롤 시점 범위는 공개되지 않았습니다.** 학습 시점(2023년 3월 초)으로 보아 ChatGPT 이후 글은 거의 없다고 봅니다.
- **instruct 데이터의 출처(ChatGPT·GPT-4 생성)는 모델 카드가 아니라 각 데이터셋의 설명에 기댑니다.**
- **200토큰을 씁니다.** 원래 Binoculars의 512토큰과 다릅니다. 08~10과 맞추기 위해서입니다.
- **쌍이 하나입니다.** Fast-DetectGPT의 README가 더 낫다고 적은 Llama3-8B/-Instruct 쌍은 이번 범위 밖입니다(Llama 3의 사전학습 데이터는 ChatGPT 이후 시점까지 포함함).
- **RAID의 사람 초록은 ChatGPT 이전 글이라 쉬운 음성 집합입니다**(04, 09와 같음).
