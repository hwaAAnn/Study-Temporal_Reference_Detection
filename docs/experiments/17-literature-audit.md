# 17. 문헌 감사: zero-shot 탐지 논문은 채점 모델의 학습 시기를 보고하나

- 브랜치: `exp/17-literature-audit`
- 상태: 명세·예측 (2026-11-17, 논문을 읽기 전)
- 위치: 논문의 주장은 "모델의 학습 시기는 **보고되지 않는** 숨은 변수"입니다. 01~16은 학습 시기가 결과를 바꾼다는 것을 보였습니다. 이 감사는 "보고되지 않는다"와 "논문 사이의 비교가 학습 시기로 교란돼 있다"를 직접 셉니다.

## 질문

1. 언어모델 확률로 글을 채점하는 zero-shot 탐지 논문 중, 채점 모델의 **학습 데이터 시기(cutoff, 크롤 기간)**를 적은 논문은 얼마나 되나?
2. 학습 시기, 또는 채점 모델의 학습 데이터에 AI 글이 섞였을 가능성을 결과에 영향을 주는 요인으로 다룬 논문은 얼마나 되나?
3. 채점 모델이 ChatGPT 이전과 이후에 걸쳐 섞인 비교(같은 표의 탐지기들)는 얼마나 흔한가?

## 표본 (읽기 전에 고정)

- **후보** (`scripts/fetch_17_candidates.py`): arXiv API에서 아래 질의 하나로 가져옵니다. 처음 제출일이 2023-01-01~2026-10-31인 논문을 arXiv id 순으로 정렬한 뒤, seed 0으로 섞은 순서를 씁니다.
  ```
  abs:"zero-shot" AND abs:detect* AND (abs:"machine-generated" OR abs:"AI-generated" OR abs:"LLM-generated"
  OR abs:"machine generated" OR abs:"AI generated" OR abs:"LLM generated")
  ```
- **선별**: 섞은 순서대로 읽으며, 다음을 만족하면 넣습니다. **30편이 차면 멈춥니다.**
  - 넣음: 열린 언어모델의 토큰 확률로 글을 채점하는 zero-shot 탐지기를 하나 이상 실험합니다(제안 방법이든 비교 기준이든). 글과 코드 모두 됩니다.
  - 뺌: 실험 없는 조사 논문, 학습한 분류기만 쓰는 논문, 워터마크, 이미지·음성·영상, 확률을 쓰지 않는 방법만 있는 논문, 원문을 읽을 수 없는 논문
  - 뺀 논문과 그 이유도 기록합니다.
- **대표 묶음** (따로 보고): DetectGPT (2301.11305), DNA-GPT (2305.17359), DetectLLM (2306.05540), Fast-DetectGPT (2310.05130), Binoculars (2401.12070). 무작위 표본에 들어 있으면 거기에도 셉니다.

## 부호화 (논문마다)

| 코드 | 정의 |
| --- | --- |
| models | 논문의 zero-shot 탐지기가 확률을 쓰는 모델 전부(채점, 표집, 기준, observer, performer). 제안 방법과 비교 기준 모두 |
| **R1** 시기 보고 | 채점 모델 중 하나라도 학습 데이터의 시기(cutoff, 크롤 기간, "~까지의 데이터")를 적었습니다. 모델 **공개 연도**만 적은 것은 세지 않습니다 |
| **R2** 시기 고려 | 채점 모델의 학습 시기, 또는 그 학습 데이터에 AI 글이 섞였을 가능성을 결과를 바꿀 수 있는 요인으로 다룹니다(한 문장이라도) |
| **P** 이후 모델 | ChatGPT 이후 데이터로 학습한 채점 모델을 하나 이상 씁니다 |
| **M** 섞인 비교 | 같은 주 비교표에 채점 모델이 ChatGPT 이전인 탐지기와 이후인 탐지기가 함께 있습니다 |

- **모델 시기 분류**: 모델 카드나 논문에 적힌 사전 학습 데이터의 끝이 2022-11-30 이전이면 "이전", 이후 크롤을 포함하면 "이후", 알 수 없으면 "모름"입니다. 분류표와 출처는 `docs/experiments/17-models.md`에 둡니다. "모름" 모델만 쓰는 논문은 P·M을 "모름"으로 둡니다.
- 근거: 코드마다 논문의 절이나 문장을 짧게 적습니다. R1·R2가 "아니오"인 논문은 본문에서 cutoff, knowledge cutoff, training data, trained on, contamination, date를 찾아본 뒤 정합니다.
- 부호화는 한 사람(Claude)이 합니다. 한계에 적습니다.

## 판단 기준 (읽기 전, 2026-11-17)

| 결과 (무작위 30편) | 판정 |
| --- | --- |
| R1 ≤ 20% 그리고 M ≥ 25% | **"숨은 변수"**: 거의 보고되지 않고, 비교가 실제로 시기에 걸쳐 섞여 있습니다 |
| R1 ≤ 20%, M < 25% | "보고 안 됨, 교란은 드묾" |
| R1이 20~50% | "일부 보고" |
| R1 > 50% | "보고됨": 논문의 "숨은" 표현을 약하게 고칩니다 |

## 미리 적어둔 예측 (2026-11-17, 읽기 전)

- **R1**: 30편 중 3편 이하(10% 이하)입니다. 확신 높음.
- **R2**: 3편 이하입니다. 학습 데이터 오염은 주로 벤치마크 오염(평가 글이 학습에 들어감)으로 다루고, AI 글 일반이 섞인 효과로는 거의 다루지 않을 것입니다.
- **P**: 전체의 50% 이상, 2024년 이후 논문의 60% 이상입니다. Llama-2/3, Mistral, Qwen, Falcon이 흔합니다.
- **M**: 30% 이상입니다. GPT-Neo·GPT-J(2020~2021 데이터) 기반 기준과 Llama-3·Qwen 기반 방법이 같은 표에 놓이는 경우가 흔할 것입니다.
- 대표 묶음 5편: R1은 0~1편입니다.
- **판정**: "숨은 변수" (약 75%).

## 한계 (미리)

- 질의가 abstract에 "zero-shot"이 있는 논문만 잡아서, 그 말을 쓰지 않는 확률 기반 탐지 논문은 빠집니다.
- arXiv 판본만 봅니다. 학회판에서 바뀐 내용은 놓칠 수 있습니다.
- 부호화는 한 사람이 합니다. R1·R2는 근거 문장을 남겨 다시 볼 수 있게 합니다.
- 모델 시기는 모델 카드에 의존합니다. 많은 모델이 데이터 끝을 밝히지 않아 "모름"이 많을 수 있습니다. 그 자체가 결과의 일부입니다.
