### 오늘 정한 것

- **논문 포지션**: 측정 도구가 주 기여이고 탐지가 부 기여입니다.
  - 측정 도구: 시간이 잘린 모델 쌍으로 AI 문체가 웹과 사람 글에 언제, 얼마나 스며들었는지 학습 없이 잽니다.
  - 탐지: AI가 다듬은 사람 글에서 기존 zero-shot 탐지기를 보완합니다.
  - 탐지만 강조하면 "Binoculars보다 나은가" 하나로 평가받고, 측정만 강조하면 "so what?"을 맞습니다. 둘을 엮습니다.
- **"왜 필요한가"의 세 집단**:
  - 사전학습 데이터를 고르는 사람들: 모델이 실제로 무엇을 흡수했는가(01)
  - AI 사용량을 추적하는 사람들: 2025년에 표지어는 줄었는데 Δ는 그대로(05)
  - 탐지 연구자들: 최근 "사람" 글이 이미 오염됨, MIA(02·05)
- **혼합 점수 s_λ = log p_2024 − λ·log p_2022**:
  - 개발 세트 탐색에서 λ = 0.75와 0.9를 골라 04 시험 전에 고정했습니다.
  - 개발 세트에서는 처음부터 AI가 쓴 글과 AI가 다듬은 글 모두에서 likelihood와 Δ 단독 이상이었습니다.
  - λ 혼합 자체는 기여로 보기 어렵습니다(contrastive decoding과 같은 꼴).
- **04의 로컬 기존 탐지기 설정**:
  - Binoculars: Llama-3.2-1B / -Instruct
  - Fast-DetectGPT: GPT-Neo-2.7B
  - gemma-3-1b-pt는 fp16에서 값이 넘쳐서 제외했습니다.
  - API 없이 공개 벤치마크(RAID 초록 13,200편, APT-Eval 6개 도메인 5,527편)를 씁니다.

### 선행연구 조사 요점

보고서는 [`docs/related-work/novelty-check-2026-11-14.md`](../related-work/novelty-check-2026-11-14.md), 갈래별 노트는 [`docs/related-work/notes/`](../related-work/notes/)에 있습니다.

- **아이디어 전체를 한 연구는 없습니다.** 근거는 가까운 논문 10여 편의 본문과, DatedGPT·ChronoGPT·PIT의 피인용 54건 전수 확인입니다.
- **이미 있는 것**:
  - 점수 식 `log p_A − log p_B`: IRM, LAPD(instruct − base)가 발표했고 MINT(ICML 2026)가 이론으로 묶었습니다.
  - 2023년 시작 시점: FineWeb 블로그의 마커 구문 곡선, Visokay et al.(웹 페이지 AI 비율)이 보고했습니다.
  - 연도별 모델로 지식 측정: Dated Data, "What Improves During Pretraining?"
- **새로운 것**: 대비 축(크롤 연도, base 대 base), 측정 대상(채팅 문체의 흡수와 확산), 통제(모델 쌍 이중차분, MIA 분리, 다듬기 보정)의 조합입니다.
  - 핵심 문장: "탐지 문헌에서 채점 모델의 학습 데이터 날짜는 통제되지 않은 숨은 변수였다. 그것을 처음 실험 변수로 바꿨다."
- **선점 위험 1순위**: PIT(Kelly et al.). 2013~2024년 체크포인트 36개가 공개돼 있고, 저자들이 "2022~2025 결과를 다음 버전에" 싣겠다고 했다가 v3에서 그 문장을 지웠습니다.
- **추가할 일**:
  - IRM을 비교 대상으로 추가합니다(04와 같은 Llama-3.2-1B 쌍, 탐색으로 표시).
  - 공개 다듬기 벤치마크(ImBD polish 분할, MIRAGE-polish)를 씁니다.
  - 둘 다 ChatGPT 이후인 쌍(2023 vs 2024)으로 대조합니다.
  - n-gram 중복으로 학습 포함 여부를 확인합니다.
  - 비원어민 글의 오탐률을 봅니다.
  - 가능하면 arXiv에 일찍 올립니다.
- **인용 주의**:
  - DatedGPT는 학회 채택이 확인되지 않아 arXiv로 인용합니다.
  - DatedGPT instruct 모델은 DeepSeek이 만든 데이터로 학습했으므로 base만 씁니다.
