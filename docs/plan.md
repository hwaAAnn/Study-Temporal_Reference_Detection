# 연구 계획: 시간에 따른 언어모델 확률 차이로 웹에 퍼진 AI 생성 글 측정하기

> 가제: *Can Temporal Differences in Language Model Likelihoods Reveal the Diffusion of AI-Generated Text Across the Web?*

## 1. 핵심 질문

2022년 말 이후 웹에는 LLM이 쓴 글이 섞였습니다. 데이터 연도만 다른 언어모델 쌍이 같은 글을 다르게 평가한다면,
**그 차이는 AI 문체가 웹에 퍼진 흔적인가, 아니면 단순한 시간 변화인가?** 그리고 그 흔적을 탐지에 쓸 수 있는가?

```
Δ_{new,old}(x) = (1/T) Σ_t [ log p_new(x_t | x_<t) − log p_old(x_t | x_<t) ]
```

이 논문의 중심은 탐지 점수 자체보다 **Δ에 섞인 원인을 분리하는 것**입니다.
가장 중요한 그림은 AUROC 표가 아니라 **2013~2024 연도별 Human/AI Δ 곡선**입니다.

## 2. Δ에 섞여 있는 세 가지 원인

| 원인 | 예시 | AI 글과 사람 글에 같은 영향? | 분리 방법 |
| --- | --- | --- | --- |
| ① AI 생성 글 노출 | 채팅 모델 특유의 표현·구조 | 아니오 (AI 글에 더 큼) | **우리가 재려는 것** |
| ② 일반적인 언어 변화 | 유행어, 문체의 자연스러운 변화 | 대체로 같음 | 이중차분(DiD), 그룹 B |
| ③ 지식 변화 | 새 사건·인물·기술 용어 | 같은 주제면 대체로 같음 | 짝 설계, k 필터(03) |
| ④ 학습 포함 여부(MIA) | 2024 모델이 그 글 자체를 학습함 | 아니오 | 2025년 이후 글만 평가, 02 실험 |

## 3. 데이터 그룹

| 그룹 | 작성자 | 시점·출처 | 역할 |
| --- | --- | --- | --- |
| A | 사람 | 2021년 이전 | 모든 vintage(≥2021)가 학습했을 수 있는 사람 글. 해석 시 "양쪽 모두 학습"임을 고려 |
| B | 사람 | **2025년 이후**, AI 사용 가능성이 낮은 출처 | 주 비교 대상. 2023~2024년 사람 글은 AI 보조 글이 섞이고 2024 모델이 학습했을 수 있어 제외 |
| C | AI | 현재 채팅/instruct 모델, B와 같은 주제 | 주 탐지 대상 |
| D′ | AI | **ChatGPT 이전 세대 모델(GPT-2, GPT-Neo)**, B와 같은 주제 | "AI라서"인지 "웹에 퍼진 채팅 문체라서"인지 가름 |

해석 규칙:
- C의 Δ만 크고 B는 작다 → ① 지지
- B의 Δ도 C만큼 크다 → ②③ 가능성(시간 변화에 민감할 뿐)
- D′의 Δ가 작다 → Δ는 "AI 일반"이 아니라 **웹에 퍼진 채팅 모델 문체**를 잡음 (가설과 일치)
- D′의 Δ도 크다 → 기계 생성 글 일반의 특성일 수 있음, 해석 수정

## 4. 핵심 설계: 이중차분(DiD)

같은 3년 간격을 AI 이전 구간과 이후 구간에서 비교합니다.

```
gap_post = mean Δ_{2024,2021}(C) − mean Δ_{2024,2021}(B)    # 일반 변화 + AI 노출
gap_pre  = mean Δ_{2021,2018}(C) − mean Δ_{2021,2018}(B)    # 일반 변화만
DiD      = gap_post − gap_pre                                # AI 노출 효과의 추정치
```

- DiD의 95% 신뢰구간(짝 단위 cluster bootstrap)이 0보다 크면, AI/사람 차이가 일반적인 시간 변화로는 설명되지 않습니다.
- 이 설계는 **"모델 두 개를 대조하는 것 자체"(Binoculars류)의 효과도 통제**합니다. AI 이전 구간 쌍도 똑같이
  "서로 다른 두 모델"이므로, 대조만으로 생기는 차이는 gap_pre에 들어가 상쇄됩니다.
- 01 실험에서는 12개 vintage 전체로 연도별 gap 곡선을 그립니다. **변화점은 미리 2023년으로 정하지 않고** 사후에 확인합니다
  (ChatGPT 공개와 실제 크롤링 시점 사이에 시차가 있음).

## 5. 사용할 모델과 확인 항목

| 모델 | 구성 | 장점 | 주의 |
| --- | --- | --- | --- |
| **DatedGPT** (`datedgpt/datedgpt-20XX-base`, 2013~2024) | 1.3B Llama 구조, 연도마다 처음부터 학습, ~100B 토큰, SentencePiece 32k, 같은 반복 수(25k) | 구조·학습량이 같고 연도만 다름 | FineWeb-Edu 기반(교육적 품질 필터가 AI스러운 글을 선호할 수 있음), 배포 정밀도 bf16 |
| ChronoGPT (`manelalab/chrono-gpt-v1-YYYY1231`, 1999~2024) | 1.55B, GPT-2 토크나이저, 전년도 모델에 이어서 학습 | 연도 해상도 높음 | 연도 효과가 누적·희석, 전용 로딩 코드 |
| TimeMachineGPT | 시간 경계를 둔 모델 계열 | 재현성 확인용 대체 계열 | 규모·공개 범위 확인 필요 |

실험 전 확인 항목(00 실험 0단계, `scripts/check_models.py`):
1. **[필수] 모든 vintage의 토크나이저가 동일한가** — 어휘와 샘플 토큰화 비교. 다르면 토큰별 비교 불가.
2. **[필수] fp16 추론이 안전한가** — GTX 1060은 bf16 미지원. GPU fp16과 CPU fp32의 log-prob 차이·inf/nan 확인.
3. 학습 데이터 양과 스텝이 vintage마다 같은가 — 논문과 모델 카드로 확인, 다르면 기록.
4. 연도 외에 파이프라인 차이(중복 제거, 필터)가 있는가 — 문서로 확인 가능한 범위만 보고.
5. 2024 데이터에 AI 생성 웹 문서가 얼마나 있는가 — 직접 측정은 불가. 기존 측정 연구를 인용하고 추정임을 명시.

## 6. 선행연구와 차이 (2026-11-12 기준 검색)

| 연구 | 쓰는 신호 | 우리와의 차이 |
| --- | --- | --- |
| Binoculars (ICML 2024) | 관련된 두 모델의 perplexity/cross-perplexity | "두 모델 대조" 자체는 같음. 우리는 **시간 경계가 다른 쌍**이고, DiD로 대조 자체의 효과를 통제 |
| Fast-DetectGPT (ICLR 2024), Lastde (ICLR 2025) | 확률 곡률, 토큰 확률 시퀀스의 시간적(위치) 변화 | Lastde의 "시간"은 문장 내 위치. 우리는 모델 학습 데이터의 연도 |
| LAPD, IRM (2026.04), Dual-network preference divergence (ESWA 2026) | base vs instruct (정렬 축) | 우리는 사전학습 데이터의 시간 축 |
| HLPD (AAAI 2026), HAPDA (ACL 2026 Findings) | 사람/기계 선호 모델을 직접 학습 | 우리는 학습 없음 |
| Human Texts Are Outliers (NeurIPS 2025) | OOD 탐지 | 학습 필요, 시간 축 없음 |
| AI-Associated Lexical Shifts Across 34 Languages (2026) | 뉴스 코퍼스의 AI 특유 단어 빈도 변화 | 단어 빈도 수준. 우리는 **모델 확률 수준**에서 측정하고 탐지에 연결 |
| Base Models Look Human To AI Detectors (2026) | 최신 base 모델 출력이 사람처럼 보임 | **반대 근거**: AI 오염이 약할 수 있음 → 00으로 확인 |
| Machine Text Detectors are MIAs (ICML 2026) | 탐지와 MIA는 같은 최적 통계량 | **가장 큰 반박 지점**: Δ는 참조 모델 기반 MIA와 수식이 같음 → 02로 분리 |
| DatedGPT (NeurIPS 2026), ChronoGPT (2025), TimeMachineGPT | 시간 잘린 모델 (lookahead bias 방지 목적) | 탐지·AI 확산 측정에 쓰인 적 없음 |

## 8. 위험 요소와 대응

1. **신호가 약할 수 있음.** → 00에서 AUROC만 보지 않고 분포·효과 크기·DiD를 함께 봄. 0.70 미만이어도 바로 접지 않고
   길이·도메인 통제, 생성기별, 토큰 유형별 진단을 **1주 안에** 거친 뒤 판단.
2. **MIA 혼동.** → B는 2025년 이후 글만. 02에서 학습 이전/이후 글로 혼동 크기를 직접 측정.
3. **시간 변화·지식 노이즈.** → 짝 설계, DiD, k 필터.
4. **"B도 순수한 사람 글이 아닐 수 있음".** → 출처 선정 기준을 문서화(예: 2025년 이후 손글씨 전사, 검증된 인터뷰 녹취, AI 사용 금지 정책이 있는 출처)하고 한계로 보고.
5. **1.3B 모델의 한계.** → 04에서 보조 신호로서의 가치 측정.

## 9. 기대 기여

1. 시간 경계가 다른 언어모델 쌍으로 **웹에 퍼진 AI 문체를 측정**하는 방법과, 시간 변화·MIA와 분리하는 **DiD 기반 통제 설계**.
2. 2013~2024 연도별 곡선: AI 문체 흡수가 **언제부터 보이는지**.
3. ChatGPT 이전 세대 AI 글(D′)과의 비교로 **무엇이 퍼졌는지**(기계 생성 일반 vs 채팅 모델 문체).
4. 학습 없는 탐지 신호로서의 성능과 기존 탐지기와의 상보성.
5. 신호가 없더라도: "시간에 따른 모델 확률 변화는 AI 문체와 무관하다"는 부정적 결과 자체가 보고 가치가 있음.
