# 연구 계획: 시간 축 참조 모델을 이용한 AI 생성 글 탐지

## 1. 문제

- 학습 없는(zero-shot) 탐지기(Fast-DetectGPT, Binoculars)와 2026년의 정렬 흔적 방식(LAPD, IRM)은
  모두 **"모델 하나 또는 base/instruct 쌍"이 보는 확률**을 신호로 씁니다.
- 정렬 흔적 방식은 "모든 회사의 정렬이 같은 방향으로 간다"는 가정에 기댑니다. IRM은 탐지기와 생성기가
  같은 계열일 때 성능이 높고, Gemma 쌍에서는 Binoculars보다 약간 낮았습니다.
- 생성 분포는 계속 바뀝니다(EvoBench, Hitting a Moving Target 2026). 특정 생성기나 정렬 방식에 기대는 신호는 늙습니다.

## 2. 아이디어

웹 텍스트 자체가 2023년 이후 AI 문체를 흡수했습니다(예: AI 특유 단어가 2023~2024 뉴스에서 늘었다는
*AI-Associated Lexical Shifts Across 34 Languages*, 2026). 그렇다면

- `p_old`: 2021년까지의 웹으로 학습한 base 모델 → "AI 이전의 사람 글 분포"
- `p_new`: 2024년까지의 웹으로 학습한 base 모델 → "AI 글이 섞인 웹 분포"

두 모델의 토큰별 log-prob 차이 Δ는 **특정 생성기와 무관하게 "웹에 퍼진 AI 문체"에 대한 노출**을 잽니다.
내용 난이도처럼 두 모델이 공유하는 요인은 빼기에서 상쇄됩니다(LAPD와 같은 논리, 축만 다름).

### 사용할 모델

| 모델 | 구성 | 장점 | 주의 |
| --- | --- | --- | --- |
| **DatedGPT** (`datedgpt/datedgpt-20XX-base`, 2013~2024) | 1.3B Llama 구조, 연도마다 처음부터 학습, ~100B 토큰, SentencePiece 32k | 구조·학습량·토크나이저가 같고 연도만 다름 → 통제 실험에 이상적 | FineWeb-Edu 기반. "교육적 품질" 분류기 자체가 AI스러운 글을 선호할 수 있음 |
| ChronoGPT (`manelalab/chrono-gpt-v1-YYYY1231`, 1999~2024) | 1.55B, GPT-2 토크나이저, 전년도 모델에 이어서 학습 | 연도 해상도가 높음 | 이어서 학습이라 연도 효과가 누적·희석됨, 전용 로딩 코드 필요 |

## 3. 선행연구와 차이 (2026-11-12 기준 검색)

| 연구 | 쓰는 신호 | 우리와의 차이 |
| --- | --- | --- |
| Binoculars (ICML 2024), Fast-DetectGPT (ICLR 2024) | 한 모델의 perplexity, 두 모델의 cross-perplexity | 시점이 다른 모델을 의도적으로 쓰지 않음 |
| LAPD (2026.04), IRM (2026.04), Dual-network preference divergence (ESWA 2026) | base vs instruct (정렬 축) | 우리는 사전학습 데이터의 **시간 축**. 정렬 방식이 바뀌어도 영향이 적음 |
| HLPD (AAAI 2026), HAPDA (ACL 2026 Findings) | 사람/기계 선호 모델을 **직접 학습** | 우리는 학습 없음 |
| Human Texts Are Outliers (NeurIPS 2025) | AI 글을 in-distribution으로 보는 OOD 탐지 | 학습 필요, 시간 축 없음 |
| SurpMark (2025) 부록 | 옛 proxy(GPT2-Large)가 새 proxy보다 약간 좋았다는 관찰 | 곁가지 관찰일 뿐, 통제된 모델 쌍이 아님 |
| Base Models Look Human To AI Detectors (2026) | 최신 base 모델 출력이 상용 탐지기에 사람처럼 보임 | **반대 근거**: 최신 base 모델의 AI 오염이 약할 수 있음 → 00 실험으로 확인 |
| Machine Text Detectors are MIAs (ICML 2026) | 탐지와 MIA는 같은 최적 통계량 | **가장 큰 반박 지점**: Δ는 수식상 참조 모델 기반 MIA와 같음 → 02 실험으로 분리 |
| DatedGPT (NeurIPS 2026), ChronoGPT (2025) | lookahead bias 없는 금융 예측용 | 탐지에 쓰인 적 없음 |

시간 잘린 모델 쌍의 확률 차이를 AI 글 탐지 신호로 쓴 연구는 찾지 못했습니다(검색 기반이므로 계속 확인 필요).

## 4. 위험 요소와 대응

1. **신호가 약할 수 있음.** 최신 base 모델도 대부분 사람 글로 학습됨. → 00 실험(2일)으로 빨리 판단.
2. **MIA 혼동.** 2024 모델의 학습 데이터에 들어간 사람 글도 Δ가 커짐. →
   평가용 사람 글은 **두 모델 모두 보지 못한 2025년 이후 글**만 사용. 02 실험에서 2024년 글 vs 2025년 글로 혼동 크기를 직접 측정.
3. **지식 노이즈.** 옛 모델은 2022~2024년의 사건·신조어를 몰라서 최신 글을 어렵게 봄. →
   (a) 같은 주제의 사람 글/AI 글을 **짝지어** 비교, (b) 03 실험에서 옛 모델이 극단적으로 놀라는 상위 k% 토큰 제외.
4. **1.3B 모델의 한계.** 단독 성능이 7B 기반 탐지기보다 낮을 수 있음. → 04 실험에서 기존 탐지기에 더하는 보조 신호로서의 가치 측정.

## 5. 기대 기여

1. 시간 축 참조 모델이라는 **새로운 학습 없는 탐지 신호**와 그 통제된 분석.
2. 연도별 12개 모델에서 **AI 문체 흡수가 언제부터 보이는지**를 보여주는 곡선(01).
3. 탐지 신호와 MIA 신호를 **분리하는 실험 설계**(02).
4. 기존 탐지기와의 상보성(04).
